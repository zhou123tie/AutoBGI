原神一条龙助手（AutoBGIManager）
==================================

睡觉时到点自动唤醒电脑 → 跑原神一条龙 → 再接力跑鸣潮日常。


【怎么打开】

双击桌面上的「原神一条龙助手」图标。

  程序   %LOCALAPPDATA%\AutoBGI\原神一条龙助手.exe
  配置   %LOCALAPPDATA%\AutoBGI\AutoBGISettings.ini
  日志   %LOCALAPPDATA%\AutoBGI\logs\autobgi.log

程序里「运行日志」页有「打开配置目录」「打开日志目录」按钮。

★ 关于管理员权限（2026-10-05 改）

  本程序已被标记为「始终以管理员身份运行」。为什么必须这样：
  ok-ww 启动 PC 版鸣潮前会检查管理员身份，**不是就直接放弃、且一行
  日志都不写**（外部只能看到一句 Start task failed，完全查不出原因）。

  以前的做法是"用到的时候临时提权"，依赖 UAC 弹窗，有两个大问题：
    · 你这台机器 UAC 设为「不提示」，提权成功也不会有任何可见反馈，
      看起来就像"什么都没发生"；
    · 若是默认 UAC 级别，凌晨三点没人能点那个弹窗。

  现在改成启动即带管理员权限，因此：
    · 双击图标 → 自动提权（这台机器不会弹任何窗口）；
    · 之后「安装任务」「立即接力一次」**都不需要再点任何东西**；
    · 凌晨自动运行本来就以最高权限跑，同样零交互。

  「自动运行」页 →「电源与登录」里有开关，可以随时取消 / 恢复。


【第一次使用（3 步）】

第 1 步：双击桌面图标

第 2 步：左侧点「基础设置」
        · 点「自动检测」找 BetterGI
        · 「一条龙」那一栏选要跑的配置

第 3 步：左侧点「自动运行」→ 点「安装 / 更新任务」
        · 弹 UAC 时点「是」
        · 日志里出现「✓ 已生效 | 下次实际运行 ...」就是成功了
        · 窗口**不会关闭**，可以继续操作


【运行链路（页面最上面那条紫色横幅）】

        🔗 运行链路
        原神一条龙 → 关闭原神 → ok-ww 跑鸣潮日常      [已启用]

整条链路一眼可见。点「去设置」可以跳到接力设置卡片。


【随机误差（默认 30 分钟）】

       实际触发 = 运行时间 ~ 运行时间 + 该分钟数
       例：03:30 + 30 分钟 → 每天在 03:30 ~ 04:00 之间随机

旁边「不随机 / 15 / 30 / 60」是快捷按钮，也可以直接填数字。
填 0 = 每天精确到点。

每天跑完之后会把**下一天**的时刻重新随机一次。
界面下方「下次实际运行」会实时显示这次抽中的具体时刻。


【游戏与执行顺序】（最重要的一张卡）

在「自动运行」页，排在「每天定时任务」下面。四个游戏：

    原神      用 BetterGI
    鸣潮      用 ok-ww
    崩坏：星穹铁道   用 三月七小助手（March7thAssistant）
    绝区零    用 绝区零一条龙（ZZZ-OneDragon）

**默认只启用「原神 + 鸣潮」**，另外两个是空框 —— 因为那两个游戏
你要先自己装好对应的开源工具。装好后在这一行勾上就能用。

  · 勾选框  = 今天跑不跑这个游戏
  · ↑ ↓     = 谁先谁后（上面那行是「执行顺序：原神 → 鸣潮」实时预览）
  · 设置路径 = 指着它告诉程序工具装在哪
  · 自动检测全部 = 让程序自己去找四个工具的安装位置
  · 测试启动…  = 挑一个游戏，真的启动一次，验证路径和参数对不对

每个游戏跑完之后，程序会自动关掉它的工具进程和游戏进程、等 20 秒
让显卡和内存释放干净，再进下一个 —— 不会出现「上一个没退、
下一个卡死」。

★ 崩铁 / 绝区零 的工具要自己去下载（本程序不附带）：

    崩铁   https://github.com/moesnow/March7thAssistant/releases
    绝区零 https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon/releases

  注意：绝区零**必须装在「全英文、不含空格」的路径**下，这是它自己的
  硬性要求；崩铁也建议放英文路径。两个工具装完都要**先手动跑一次**，
  在它们自己的界面里配好游戏路径、下载资源、确认能正常完成日常。

  这个程序只负责「按顺序启动它们、等它们跑完、清理进程」，
  实际的游戏操作全部由这些开源工具完成。


【接力鸣潮（Wuthering Waves）】

「自动运行」页的接力卡片。开启后，每天会自动：

       原神一条龙跑完
         → 关闭 BetterGI 和原神
         → 交给 ok-ww
         → ok-ww 自己启动鸣潮 → 跑鸣潮日常 → 结束后退出游戏

★ 「是否跑鸣潮」现在由上面的「游戏与顺序」统一控制
  （勾选框就是开关），这张卡里只需配好 ok-ww 的路径和选项。

★ 重要：**鸣潮是由 ok-ww 自己启动的**，本程序不另外开游戏。
   这是 ok-ww 的正常流程 —— 它的 start_device() 发现游戏没开时
   会自己 starting game 并等窗口就绪。

★★ 关于「ok-ww.exe」和「日常一条龙」（容易误会，务必看这段）

  你双击的 ok-ww.exe 是个**启动器**（窗口标题 ok-ww，上面有
  「启动应用」按钮和「自动启动」开关）。点「启动应用」的本质就是
  用它自带的 python 跑 `main.py`（不带参数 → 打开 ok-ww 主界面）。
  **ok-ww.exe 自己不转发任何命令行参数**，所以没法直接给它传
  「跑哪个任务」——本程序必须用 ok-ww 自带的 python 直接跑 main.py。

  所以本程序启动 ok-ww 时跑的是：
      python.exe main.py -t DailyTask -e
  其中 `-t DailyTask` 就是 ok-ww **主界面 → Tasks 页**里第一项
  「📅 Daily Task」，它的官方说明是：
      Login, claim monthly card, farm echo, and claim daily reward
  即 **登录 + 领月卡 + 刷声骸 + 领日常奖励** —— 这就是你要的
  「日常一条龙」。跑完还会按你在 ok-ww 里配的
  「Additional Tasks to Run After Daily Task」继续跑（你现在配的是
  「自动周常乐园 Check Weekly Garden」）。

★ 现在默认会**显示 ok-ww 的程序界面**（窗口标题 OK-WW）：
  跑接力时你能亲眼看到 ok-ww 自己打开、跑日常、结束。
  （之前版本写死了无界面参数，ok-ww 完全在后台静默跑，
   看起来像"根本没启动"。）
  想让它安静地在后台跑，就把「跑鸣潮时显示 ok-ww 的程序界面」
  的勾去掉。

  两种方式都是**自动执行**，不需要点任何按钮，也不需要按 F9。

★ 跑原神那一段时，本程序会**自动把其它窗口全部最小化，只留原神**
  （默认开启，可在「电源与登录」里关掉）。具体是：

    · 原神窗口              保留（会一并置到最前）
    · BetterGI 的**遮罩窗口** 保留（它画在游戏上，最小化会让 BGI 失效）
    · **BetterGI 的程序主窗口（标题「更好的原神」）也会被最小化**
    · 任务栏                  保留（只占底部一条，全屏游戏会盖住它；
                                   最小化它会让整条任务栏消失，更糟）
    · 其余全部窗口（浏览器、聊天窗口、资源管理器……）一起最小化

  这样 BetterGI 的截屏识别和模拟键鼠才不会被别的窗口干扰 ——
  「切换角色卡住，执行脱困」反复刷、一卡几小时，根因就是这个。
  被最小化的窗口从任务栏恢复即可，不影响它们运行。

★★ 睡眠唤醒后卡在「开始菜单」上（重要）

  你会碰到的一种情况：电脑睡了一觉醒来，屏幕上停着**按了 Win 键
  才出现的那个界面**（开始菜单 / 搜索）。它一旦抢走焦点，游戏就收不到
  模拟键鼠、BetterGI 也识别不到画面 —— 整条链路当场停摆。

  这个界面很特殊：在 Win11 上它不是独立窗口，而是寄居在
  explorer.exe / searchhost.exe 里的浮层，**普通"最小化其它窗口"
  根本碰不到它**。

  现在的处理（默认开启，可在「电源与登录」里关掉）：
    · 启动 BetterGI **之前**先检查一次，发现就按一下 Esc 关掉；
    · 一条龙跑着的时候每分钟再看一次，发现了立刻关掉并把原神置前；
    · 交给 ok-ww 之前也检查一次（它同样靠截屏操作）。
  Esc 是关闭它的标准方式，实测干净有效，不会影响游戏本身。

  建议勾上「接力时关闭原神」，把显卡/内存让给鸣潮。

★★ 管理员权限（手动接力必须满足）

  ok-ww 在启动 PC 版鸣潮前会检查自己是不是管理员，**不是就直接放弃**，
  而且一行日志都不写 —— 外部只能看到一句 Start task failed，
  完全猜不出原因（2026-10-05 02:16 就卡在这里）。
  注：鸣潮主程序本身的清单也要求管理员，所以这一条绕不过去。

  现在本程序**启动时就带管理员权限**（见前面「关于管理员权限」），
  所以点「立即接力一次」不会再有任何提权动作。

  万一程序没带权限（比如你把那个兼容性标记去掉了），它会按顺序尝试：
    ① 启动「按需接力任务」AutoBGI_Relay —— 这是安装时创建的一个
       无触发器的最高权限任务，由计划任务服务拉起，不需要 UAC；
    ② 退回到临时提权（可能会弹 UAC）。

  「鸣潮主程序」那一行显示的是 **ok-ww 会用哪个文件启动游戏**。
  如果显示红色的 ✗，说明 ok-ww 的设备记录指向了已经失效的旧路径
  （它那时会报 Game path does not exist，游戏开不起来）——
  点下面的「修正 ok-ww 游戏路径」一键改好。

想立刻试一次，点「立即接力一次」（会关掉正在运行的原神，有确认框）。

判断依据：BetterGI 日志里出现「一条龙和配置组任务结束」才算跑完。
一条龙被取消或超时也会继续接力；但压根没开跑就**不会**接力。


【点了按钮怎么知道有没有反应】

  · 悬停 → 变色；按下 → 变深
  · 处理中 → 按钮变「处理中…」带跳动点，同时禁用
  · 底部状态栏 → 绿点 + 当前在做什么 + 第几步 + 来回滑动的进度条
  · 完成 → 按钮闪一下：绿「✓」= 成功，红 = 出错
  · 所有过程都写进「运行日志」页


【改了设置怎么确认真的生效】

1. 改完点「安装 / 更新任务」
   → 日志出现「✓ 已生效 | 下次实际运行 ...」就是成功
   → 失败会写明原因，不会"点了没反应"

2. 点「验证是否生效」
   → 把「你的设置」和「系统里真实的设置」并排列出来对照


【「允许运行的时间窗」怎么填】

不用管，留 0000-0000（不限制）就行，或点「不限制（推荐）」。
设了窄窗会跟任务时间打架，任务被自己的时间窗挡住而静默跳过。
开了随机误差时，窗口上沿会自动外扩。


【出问题了怎么办】

1. 改了设置却"完全没变"
   点「验证是否生效」。程序**一打开**就会自检配置能否写入，
   不能写会在日志里红字警告。

2. 双击没反应
   看 %LOCALAPPDATA%\AutoBGI\AutoBGI_crash.txt

3. 任务没跑 / 跑了但没启动游戏
   看 logs\autobgi.log 最后几行

4. 鸣潮没跑起来（ok-ww 报 Start task failed）
   先看「检测各程序」里的「管理员权限」是不是 ✗。
   ok-ww 非管理员时**静默放弃**，日志里查不出原因 —— 这是最常见的真因。
   再看「鸣潮主程序」是不是红色 ✗，是就点「修正」；
   最后看 ok-ww 自己的输出：
   %LOCALAPPDATA%\AutoBGI\okww_last_run.log

5. 鸣潮跑到一半自己没了（日志里出现 exists:0）
   这不是 ok-ww 的问题 —— ok-ww 已经连上窗口、图像识别成功、
   正在游戏里操作，然后游戏窗口忽然消失。
   判断是不是真的崩了，看这个目录有没有**新增的子文件夹**：
     C:\Wuthering Waves\Wuthering Waves Game\Client\Saved\Config
       \CrashReportClient
   有新增 = 游戏自己崩了。建议：
     · 打开鸣潮启动器做一次「校验 / 修复文件」
     · 在游戏里把分辨率手动设成 1920x1080（显示器的原生分辨率），
       免得 ok-ww 每次去调整窗口大小
     · 手动启动一次鸣潮看看是否也崩 —— 若也崩，就是游戏侧的问题

6. 原神一条龙跑到一半卡住（进度长时间不动）
   典型迹象：BetterGI 日志里反复刷「切换角色卡住，执行脱困」。
   根因多半是**别的窗口盖住了游戏、或抢走了焦点** —— BetterGI 靠
   截屏识别 + 模拟键鼠工作，一旦游戏收不到输入，它就会一直在那里打转
   （2026-10-05 凌晨实测：卡在自动秘境，空转 806 次、白等 5 小时）。

   现在的处理（默认开启，不用你管）：
     · 开跑一条龙时**自动把其它窗口全部最小化**，只留原神
       （BetterGI 自己的遮罩窗口会保留，不影响它工作）；
     · **顺手关掉开始菜单 / 搜索**这种浮层（见上一节的详细说明）；
     · 原神窗口出现时再清一次桌面；
     · 万一还是卡住：先自动「清桌面 + 把原神置前」，再观察 3 分钟；
     · 仍然卡 → 提前结束原神部分、直接转去鸣潮接力，不再干等几小时。

   相关开关（「自动运行」页 →「电源与登录」）：
     · 开跑一条龙时把其它窗口全部最小化（只留原神）  ← 默认开
     · 开跑时自动关掉开始菜单 / 搜索                  ← 默认开
     · 一条龙运行时让显示器保持常亮                  ← 默认关

   想手动调判定阈值，改配置文件里这两项：
     OneDragonStuckHits      脱困出现多少次算异常（默认 40）
     OneDragonStuckQuietMin  进度多少分钟不动算卡（默认 6）

7. 鸣潮那边出问题
   · 提示「鸣潮崩溃后 ok-ww 卡死（已主动终止）」
     说明鸣潮自己崩了（游戏侧问题）。到
     C:\Wuthering Waves\Wuthering Waves Game\Client\Saved\Config\
     CrashReportClient\ 看有没有新增的 UE4CC-Windows-* 目录。
     有的话建议用鸣潮启动器做一次「校验 / 修复文件」，
     并把游戏分辨率设成和显示器一致（你现在是 1920x1080）。
   · 提示「ok-ww 报告任务启动失败」
     先看「检测各程序」里「管理员权限」是不是 ✗ ——
     ok-ww 非管理员时会**静默放弃**，日志里查不出原因。
   · 想看 ok-ww 的原始输出：
     %LOCALAPPDATA%\AutoBGI\okww_last_run.log

8. 想确认系统里到底装了几个任务
   点「查看全部启动项」
